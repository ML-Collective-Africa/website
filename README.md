# MLC Africa website

The website for ML Collective Africa, built with Next.js.

## Getting started

```bash
cp .env.example .env.local
npm install
npm run dev
```

Then open http://localhost:3000.

## Admin

Go to `/admin` and sign in with the `ADMIN_EMAIL` and `ADMIN_PASSWORD` from your `.env.local`.

## Scripts

- `npm run dev` starts the development server
- `npm run build` builds for production
- `npm start` runs the production build
